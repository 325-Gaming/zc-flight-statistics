# 部署、配置与排查

## 配置归属

本文只列配置项和职责，不记录配置值。数据库凭据、会话、邮件认证和宿主机器人接入信息由各服务部署配置维护。

| 所属组件 | 配置项或入口 | 说明 |
| --- | --- | --- |
| gachabot | 插件目录 `.env` 与 `config.py` | 数据库配置使用 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_DATABASE`、`DB_CHARSET`、`DB_AUTOCOMMIT`；现有机制为进程环境优先于插件配置文件 |
| gachabot | `ZCFLIGHT_PERMISSION_INFO_URL` | kusabot 内部权限查询入口；跨主机使用受信任网络或 TLS，变更后重启服务 |
| kusabot | `plugins/kusa/config.py` 与对应配置模板 | 用户、数据库、登录和邮件等配置沿用该服务自身机制，不在客户端另存后端凭据 |
| 客户端 | `.env.example` 所列 `ZCFLIGHT_*_URL` | 可覆盖的认证、模型、历史、乘客与显示接口地址；更改后重启客户端 |
| 客户端 | `config.example.json` | 活动、卡池、显示器、乘客名单与快捷键等运行设置的模板 |
| 静态站点 | 页面、主题和头像资源 | 由 `yubo.run` 部署；业务 API 仍由对应后端提供 |
| 官方更新 | 本仓库策略、版本文件和 Release 工作流 | 地址固定在客户端更新机制中，不随普通业务接口配置改写 |

客户端认证模块使用 `dotenv_values()` 直接读取配置字典；业务入口使用 `load_dotenv()` 后读取进程环境。两者的现有加载方式不同，不能假定所有配置都会自动写入或统一覆盖进程环境。

当前客户端并非所有地址都可配置：抽卡提交地址、个人中心登录页和直播页基础地址仍固定在源码中；活动列表、直播配置管理和乘客状态接口从 `ZCFLIGHT_CURRENT_USER_URL` 按同目录路径派生。只修改部分接口地址不能完成整套服务迁移。模型清单返回的下载路径也必须与实际代理前缀一致。

## 部署依赖与迁移

1. 明确目标客户端、gachabot、kusabot 和前端的兼容版本，以及现有数据库结构。迁移前停止相关写入并完成备份，保留可核查的版本与迁移记录。
2. 先准备 kusabot 的结构化权限与基础活动能力，部署对应个人中心，创建真实基础活动并确认机长、乘务员关系。不得从活动名称猜测 UUID 或操作员账号编号。
3. 审核 gachabot 的活动、操作员与卡池作用域迁移。迁移说明位于该仓库的 `FLIGHT_AUTH_MIGRATION.md`，相关脚本为 `migrations/20261101_zc_flight_scope.sql`；其中存在环境专用映射，不能直接套用于新环境或重复执行。
4. 如版本包含赠送功能，再核对 `migrations/20261101_zc_flight_gift.md` 与同名 SQL 的前置条件。赠送列与卡池奖励规则必须在服务端接受相关请求之前就绪。
5. 协调部署 gachabot、直播页、静态资源与兼容客户端。赠送功能的依赖顺序为服务端和数据库就绪 → 直播页与共享样式 → 客户端。活动作用域切换应与客户端兼容安排在维护窗口，不能在迁移后恢复旧客户端写入。
6. 确认新版稳定 Release 可下载并通过校验，再单独提高客户端最低版本策略。具体活动迁移与客户端发布的维护窗口安排参考仓库根 README，不用一条固定顺序代替兼容性核对。

`live_page_schema.sql` 用于全新安装的直播配置表结构说明，不能当作已有部署的完整升级脚本，也不能据此假定整个业务库已经初始化。MySQL DDL 可能隐式提交，不能用事务回滚代替迁移前备份。

卡池名称、限定属性、赠送开关及赠送对象由服务端已有卡池配置机制维护。多名当期限定时需明确指定赠送对象；不支持 300 抽奖励的卡池应明确关闭该能力。这里不收录实际卡池配置文件或完整内容。

回滚前先检查数据兼容性。旧服务端不识别赠送记录时，必须按赠送迁移说明处理有效赠送；不能仅回退程序而继续让旧版统计读取不兼容数据。恢复数据库和回退程序应使用同一经确认的恢复方案。

## 验收范围

| 场景 | 需要确认的结果 |
| --- | --- |
| 登录、退出和过期会话 | QQ／邮箱登录可用，退出后后续请求失效，无效会话不能写入 |
| 权限与活动 | 机长、乘务员、撤权账号、全局管理员各自符合边界，跨活动访问被拒绝 |
| 多操作员、多卡池 | 历史、顺序、当前乘客和直播统计正确隔离 |
| 提交与历史操作 | 去重、撤销、恢复、排序结果一致，失败任务可识别并核查 |
| 赠送 | 对象、重复领取、撤销与恢复正确，赠送不增加实际抽数 |
| 直播配置 | 创建、授权、移除、默认切换和编辑冲突符合预期 |
| 显示状态 | ON AIR、主题、显隐和刷新间隔对应所选配置；停用链接不回退其他活动 |
| 模型分发 | 清单与文件一致，认证、大小及 SHA-256 校验有效，首次安装资源完整 |
| 客户端更新 | 策略可用，稳定包与标签一致，强制更新和失败恢复流程可用 |
| 实际界面 | Windows WebView2、macOS WebView 与 OBS 分别验证登录、主题、链接和长文本显示 |

本地模拟测试不能替代真实数据库结构、代理路由、认证上游和原生窗口验收。本轮仅编写文档，不执行迁移、不发送群通知、不进行真实业务写入。

## 常见问题定位

| 现象 | 优先检查 |
| --- | --- |
| 启动停在更新门禁 | 官方策略网络与格式、最低版本、稳定更新包及待恢复事务；不是先更换业务 token |
| 登录成功但无可用活动 | `permission_list` 结构、航空活动作用域及实际机长／乘务员关系 |
| gachabot 返回 401／403 | 会话有效性、认证头与标识、当前活动权限及目标配置授权 |
| gachabot 返回 503 | kusabot 权限查询连通性及响应；若为模型接口，再检查模型元数据与文件 |
| 保存显示设置返回 409 | 默认配置是否在读取后改变；重新读取并确认目标后再保存 |
| 有效直播链接返回 404 | 配置是否已移除、停用或 ID 错误；不要改用默认入口掩盖问题 |
| 统计与历史不同 | 活动、操作员、卡池、固定乘客、撤销状态及赠送统计口径 |
| 历史能读取但提交失败 | 提交地址仍为固定入口，其他可覆盖接口可能已指向不同环境 |
| 主题缺失或退回 classic | 主题目录接口、CSS 实际发布位置及网络加载结果 |

排查记录保留组件版本、时间、接口路径、HTTP 状态与脱敏后的错误描述即可；不要附带认证头、会话文件、真实配置或数据库转储。
