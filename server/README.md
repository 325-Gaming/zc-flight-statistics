# 服务端说明

本目录整理 `client/data-entry` 使用的 gachabot 及相关服务，供维护、联调和部署交接使用。只记录职责、接口契约、配置项名称和运维要求，不包含实现代码、可执行部署脚本、真实账号、会话、密钥、数据库连接值或环境专用的数据映射。

核对日期：2026-11-03。内容依据本地工作区源码，包括尚未提交的功能；不代表对应提交已经发布、数据库已经迁移或生产服务已经验收。线上状态应在部署时另行核实。

## 服务关系

| 组件 | 归属仓库 | 与客户端的关系 |
| --- | --- | --- |
| gachabot | `nonebot-plugin-zc-gachabot` | 抽卡提交、历史管理、乘客状态、直播配置、模型清单与下载 |
| 羽bot后端（kusabot） | `kusabot` | 登录验证、退出、权限查询和基础活动管理；同时作为 gachabot 的认证上游 |
| 个人中心 | `yubo.run` 的 `user/` | 客户端内打开的 QQ／邮箱登录页面及活动管理入口 |
| 直播页与静态资源 | `yubo.run` 的 `zc/` 等目录 | OBS 页面、共享主题、头像等展示资源 |
| 数据库 | kusabot 与 gachabot 使用的 MySQL 数据库 | 用户、权限、活动、抽卡记录、直播配置和模型清单元数据 |
| GitHub | 本仓库及官方 Release | 最低版本策略、版本提示、客户端更新包与校验信息 |

客户端的典型流程为：在线验证更新策略 → 个人中心验证会话和权限 → 获取模型与活动信息 → 同步当前乘客 → 进入录入界面。业务请求由 gachabot 校验会话与权限后读写数据库；直播页独立读取公开统计接口。

## 地址与范围

客户端默认使用 `https://yubo.run`。外部业务地址前缀为 `/api/zc-flight/`，认证地址前缀为 `/api/kusa/`；后端源码注册的路径分别为 `/zc-flight/` 和 `/kusa/`。部署入口需要完成对应转发，不能直接把外部路径当作后端注册路径。

本目录的接口表记录方法和路径，不提供请求代码或真实请求样本。路径、字段名和配置项名称不是凭据；实际身份信息、访问值和部署参数应由各服务现有的配置管理方式维护。

不在此处覆盖 gachabot 的群聊抽卡、OCR 等其他功能，也不将这些功能视作桌面录入的必备远程识别服务。当前客户端在本机通过 ONNX 执行识别。
